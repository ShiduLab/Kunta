# Kunta

**Versione mobile / PWA — ShiduLab 2026**

Kunta è un piccolo laboratorio testuale che conta, osserva, ordina e rac-conta i testi.
Questa versione gira nel browser del telefono, può essere aggiunta alla schermata Home e, dopo il primo caricamento, funziona offline.

## Cosa c'è già

La versione mobile porta le funzioni della build Windows attuale, tra cui:

- conteggi di caratteri, parole, righe, spazi, cifre e punteggiatura;
- frequenze e ripetizioni;
- **Ordina parole alfabeticamente**;
- palindromi, bifronti, anagrammi, acrostici e telestici;
- schema rime / desinenze;
- rima baciata / inclusione progressiva;
- LetterTransport;
- sciarade / candidati a salti di dominio;
- **Kunta il testo (fenomeni)**.

Il testo viene elaborato localmente nel dispositivo: la pagina non invia il contenuto a servizi esterni.

## Uso sul telefono

1. Apri Kunta nel browser.
2. Incolla, scrivi oppure apri un file testuale.
3. Scegli l'operazione e premi **KUNTA!**.
4. Copia o condividi il risultato.

Su browser compatibili, una volta installata come PWA Kunta può comparire anche tra le destinazioni di condivisione del testo.

## Pubblicazione rapida con GitHub Pages

Carica il contenuto di questa cartella in un repository GitHub oppure in una cartella `docs/` del repository Kunta.
Poi abilita **Settings → Pages** e pubblica il branch/cartella scelta.

La PWA deve essere servita via HTTPS perché installazione, Service Worker e funzioni di sistema siano pienamente disponibili. GitHub Pages fornisce HTTPS.
