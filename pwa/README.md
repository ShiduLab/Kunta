# Kunta PWA

Versione web installabile di Kunta, allineata al motore Desktop del 16 settembre 2026.

- 58 operazioni linguistiche.
- Anagrammi cercati nel dizionario italiano indicizzato da oltre 4,2 milioni di voci.
- Articoli/elisioni esclusi dalla parola analizzata negli anagrammi.
- Varianti identiche con soli accenti grafici non vengono proposte come anagrammi.
- Omovocaliche e omoconsonantiche raggruppano per materiale ma mostrano l'ordine reale nella parola.
- Parole alfabetiche: solo successioni consecutive (ABC, BCD; inverse CBA, FED).
- Caratteri e parole mostrano anche le frequenze.
- Palindromo inverso, Palindromo contrario, Inversi e Antipodi restano operazioni distinte.
- Il dizionario anagrammatico viene mantenuto in cache dal Service Worker per l'uso offline.

L'analisi resta locale nel browser.
